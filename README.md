# fahadmohamed.in — Portfolio

Static, responsive portfolio website for Fahad Mohamed, built for Netlify.

## Deploy on Netlify

1. Put these files in a GitHub repository.
2. In Netlify, choose **Add new project / Import from Git** and select the repository.
3. Build command: leave blank.
4. Publish directory: `.`
5. Add the custom domain `fahadmohamed.in` in the Netlify domain settings.

The site has no build dependency and can be hosted on Netlify's free static hosting.
